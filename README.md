# Web Technologies Assignment 01

## Overview
This repository is a static HTML/CSS learning project for Web Technologies. It presents six lecture-style pages and examples covering core web concepts, from how the web works to HTML structure, forms, CSS styling, and the CSS box model.

The site is educational and front-end only. It does not include JavaScript logic, backend processing, authentication, or database persistence.

## Learning Topics Covered
- Introduction to the Web (Internet, browsers, URLs, DNS, HTTP/HTTPS)
- Web applications and architecture (static vs dynamic, MPA/SPA/PWA, tiers)
- HTML structure and content (document structure, text, links, lists, tables)
- HTML5 semantic elements and forms
- Browser-side form validation basics
- CSS basics, selectors, cascade/specificity, and text/background styling
- CSS box model, sizing, spacing, overflow, and display behavior

## Technologies Used
- HTML5
- CSS3

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Navigate through lectures using the home table and page navigation links.

> `lecture4.html` includes a practice form demo that uses browser validation and submits with `method="get"` to `form-practice.html`. It is a static demonstration and does not store submitted data.
