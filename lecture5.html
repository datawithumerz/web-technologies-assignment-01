LECTURE 5

CSS Basics, Selectors and Styling

CSS controls the appearance of HTML. A rule selects some elements and describes how they should look. Learning to select the right elements is just as important as learning the properties.

On this page

  • CSS syntax and stylesheets
  • Selectors and relationships
  • Pseudo-classes and pseudo-elements
  • Cascade, specificity and inheritance
  • Colour, fonts, text and backgrounds

1. Read a CSS rule

CSS means Cascading Style Sheets. It separates presentation from the HTML content, making the same design easier to apply across several pages.

p {
    color: darkgreen;
    font-size: 18px;
}

p is the selector. It chooses paragraph elements. Inside the braces are declarations. Each declaration has a property, a colon, a value and a semicolon. Here, color is a property and darkgreen is its value.

Three places to write CSS

Ways to attach CSS
TypeLocationScope
InlineAn element's style attributeThat element
InternalA <style> element in the document headThe current document
ExternalA separate .css file linked from the headEvery document that links it

Here are the first two forms as short syntax examples:

<!-- Inline CSS -->
<p style="color: green;">A green paragraph.</p>

<!-- Internal CSS, placed inside head -->
<style>
    p {
        color: green;
    }
</style>

For several related pages, an external file is easier to maintain. Put the declarations in style.css without any <style> tags, then add this line inside each page's <head>:

<link rel="stylesheet" href="style.css">

Changing one shared rule can update every linked page. If the design does not appear, first check the filename and path in href.

2. Select the elements you want

Basic CSS selectors
SelectorExampleWhat it selects
ElementpAll paragraphs

Groupingh1, h2All matching h1 and h2 elements

A class is reusable. Several notes can share class="note". An ID should identify one element within the page. The dot and hash belong in CSS selectors, not in the HTML attribute values.

<p class="note">Save the HTML file before refreshing.</p>
<p id="intro">Welcome to CSS.</p>
.note {
    background-color: #f1f4ed;
}

#intro {
    font-weight: bold;
}

Select by relationship

A combinator describes how elements relate to one another. These selectors help target an area without adding a separate class to every child.

Relationship selectors
ExampleMeaning
.lesson pAll paragraphs anywhere inside an element with class lesson.
.lesson > pOnly paragraphs that are direct children of that element.
h2 + pA paragraph immediately following an h2 with the same parent.
h2 ~ pAll later paragraph siblings of an h2 with the same parent.
<div class="lesson">
    <p>Direct child paragraph.</p>
    <section>
        <h2>More information</h2>
        <p>Nested paragraph.</p>
    </section>
</div>

.lesson p matches both paragraphs. .lesson > p matches only the first one. The difference is the space versus the greater-than sign.

3. Style a state or a part

A pseudo-class selects an element according to its state or position. It normally uses one colon. For example, :hover matches when the pointer is over an element, and :focus matches the currently focused element.

a:hover {
    color: brown;
}

a:focus {
    background-color: #fff2cc;
}

tbody tr:nth-child(even) {
    background-color: #f3f5ef;
}

The last rule shades alternating body rows in a table. Other useful pseudo-classes include :first-child, :last-child, :active, :visited and :disabled.

A pseudo-element targets a part of an element, or creates generated content. It uses two colons. For example:

.opening::first-letter {
    font-size: 28px;
    color: darkgreen;
}

.tip::before {
    content: "Tip: ";
    font-weight: bold;
}

::first-letter styles the first letter. ::before inserts generated content before an element's normal content. Other examples include ::after, ::first-line and ::selection. Keep essential instructions in the HTML so the content remains clear without the stylesheet.

4. When more than one rule matches

The cascade is how CSS resolves competing declarations. For ordinary rules in one author stylesheet, selector specificity and source order explain many everyday conflicts. Origin and importance also matter, so source order alone does not always decide the result.

Specificity

<p id="welcome" class="message">Hello CSS</p>
p {
    color: green;
}

.message {
    color: blue;
}

#welcome {
    color: red;
}

All three rules select the paragraph, but the ID selector is more specific. Under these conditions, the paragraph will be red. A class selector is more specific than an element selector.

Specificity examples: IDs, classes, elements
SelectorSpecificity
#welcome1-0-0
.message0-1-0
input[type="text"]0-1-1
p0-0-1
*0-0-0

Compare these parts from left to right, rather than adding them into one score. Classes, attributes and pseudo-classes contribute to the middle part. Elements and pseudo-elements contribute to the last part. Ordinary inline declarations take precedence over ordinary author stylesheet rules for that element.

Source order

p { color: blue; }
p { color: green; }

Both selectors have equal specificity and the other conditions are equal, so the later declaration wins. The paragraphs become green.

Inheritance

Some properties pass from parents to children. If body sets a font, its paragraphs usually inherit it unless another rule sets their font. Properties such as margins, padding and borders do not normally inherit.

body {
    color: #28322e;
    font-family: Arial, sans-serif;
    line-height: 1.7;
}

inherit explicitly uses the parent's value. initial uses a property's initial value. unset acts like inherit for naturally inherited properties and like initial for the others.

If a style does not work: check that the stylesheet loads, the selector matches, the declaration is valid, and another rule is not winning. Changing random properties makes the problem harder to understand.

5. Colours, fonts and readable text

color controls text colour. background-color fills the background. You can express a colour by name, hexadecimal notation, RGB or RGBA.

/* Different ways to describe red */
color: red;
color: #ff0000;
color: rgb(255, 0, 0);

/* Red with 50% opacity */
color: rgba(255, 0, 0, 0.5);

font-family sets a typeface and its fallbacks. A serif font has small finishing strokes, a sans-serif font has simpler letter endings, and a monospace font gives characters equal widths. Monospace is useful for code.

A small styled example

<p class="demo-text">Clear text makes learning easier.</p>
.demo-text {
    color: #205c50;
    font-family: Georgia, serif;
    font-size: 20px;
    text-align: center;
    background-color: #edf2e7;
    padding: 16px;
}

Background images

A background image appears behind the content. A fallback colour keeps the area readable if the image cannot load. Use an image file that exists at the given path.

.banner {
    background-color: #e7ece3;
    background-image: url("paper.jpg");
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}

no-repeat stops tiling, center centres the image, and cover scales it to cover the box, possibly cropping some edges. A background is decoration; use an HTML image with alternative text when the picture itself carries important information.

Try it yourself

  1. Link two HTML pages to the same stylesheet and change their heading colour with one rule.
  2. Give two paragraphs the same class and style them together.
  3. Predict the winning colour in the specificity example, then remove the ID rule and predict it again.
  4. Add a hover style to a link and keep a visible focus style for keyboard users.
