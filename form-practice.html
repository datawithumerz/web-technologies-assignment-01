LECTURE 4 EXAMPLE

Where does a form go?

If you arrived by submitting the practice form, the browser checked its required fields, registration pattern and number limits before opening this page.

Look at the address bar. A GET submission adds named values after a question mark. The URL can contain values such as reg=FA24-BSE-084, marks=85 and topic=html, separated by ampersands.

This is a static demonstration. The page does not read your submitted values or save them to a database. A real registration system needs a server to process and validate the data.

You can also open this page directly, so seeing it by itself is not evidence of a successful form submission.
