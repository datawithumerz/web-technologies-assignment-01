Understand how a web page works.

A web page starts with content. HTML gives that content a structure, and CSS makes it easier to read and use. Before writing either, it helps to understand how a browser gets a page in the first place.

These lessons follow that path: from the Internet and web applications to building and styling your own pages. Each lesson explains the main ideas, works through examples, and ends with a small task to try.
