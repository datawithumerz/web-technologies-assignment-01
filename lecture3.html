HTML Structure and Content

HTML tells the browser what your content means. A heading introduces a topic, a paragraph explains it, and a link connects it to another resource. Choosing the right element gives the page a useful structure.

1. Start with a complete HTML document

HTML means HyperText Markup Language. It marks up content using elements. It describes structure rather than performing calculations or running application logic.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Page</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Learning HTML</h1>
    <p>This is my first paragraph.</p>
</body>
</html>
<!DOCTYPE html>
Declares an HTML document and helps the browser use standards mode. It is a declaration, not a normal content element.
<html lang="en">
The root element contains the document. The lang attribute identifies English as the page language.
<head>
Contains information about the document. The character encoding supports text characters, the viewport setting helps with mobile display, and <title> supplies the browser tab title.
<link>
Connects the page to another resource. Here, rel="stylesheet" and href="style.css" connect the external CSS file.
<body>
Contains the page content visitors read and use.

Tag, element and attribute

<a href="lecture4.html">Read about forms</a>

<a> and </a> are tags. The complete anchor, including its content, is an element. href="lecture4.html" is an attribute that gives the link its destination. Attribute values usually belong in quotes.

Some elements are void elements, such as <img>, <br> and <meta>. They do not wrap content and have no closing tag in HTML.

Nesting and the DOM

Elements can contain other elements. Close them in the reverse order from opening them. The browser represents the document as a tree called the Document Object Model (DOM). In the example below, strong is inside the paragraph.

<p>Save your work <strong>before closing the editor.</strong></p>

The <strong> element closes before </p>. Good indentation makes these parent and child relationships easier to follow.

2. Organise and explain with text

Use <h1> for the main page heading. Use <h2> for major sections and <h3> for sections within them. HTML provides headings through <h6>. Choose levels according to the content hierarchy, then use CSS to control their visual size.

<h2>Learning HTML</h2>
<h3>Why structure matters</h3>
<p>A clear structure helps readers find information.</p>
<p>Use <strong>important words</strong> carefully.</p>

Useful text elements
ElementMeaning and use
<p>A paragraph containing a connected piece of text.
<strong>Strong importance, often displayed in bold.
<em>Stress emphasis, often displayed in italics.
<mark>Text highlighted because it is relevant in the current context.
<del> / <ins>Content that was deleted or inserted.
<br>A line break, useful within an address or poem.
<hr>A thematic break between parts of the content.
<code> / <pre>Computer code, and text whose spacing and line breaks should be preserved.

Use separate paragraphs for separate ideas. Repeated <br> tags are a poor way to create page spacing because spacing belongs in CSS.

How do you show a tag as text? Write &lt; for the less-than sign and &gt; for the greater-than sign. For example, &lt;p&gt; displays as <p>. This keeps an example from becoming a real paragraph element.

3. Connect pages and add media

An anchor element, <a>, becomes a hyperlink when it has an href. Use meaningful link text so the destination is clear.

<a href="https://example.com">Visit Example</a>
<a href="lecture4.html">Learn about HTML forms</a>
<a href="#tables">Jump to tables</a>
  • An absolute URL includes the scheme and host, such as https://example.com.
  • A relative path, such as lecture4.html, points from the current page's location.
  • A fragment link, such as #tables, jumps to an element with a matching id="tables".

Images

<img src="student.jpg"
     alt="A student reading a web development book"
     width="400">

src gives the image location. alt provides a text alternative for an informative image. width sets its displayed width in pixels in this example. The file student.jpg must exist at the given path when you try this code.

Audio and video

<audio controls>
    <source src="lesson.mp3" type="audio/mpeg">
    Your browser does not support this audio.
</audio>

<video controls width="400">
    <source src="lesson.mp4" type="video/mp4">
    Your browser does not support this video.
</video>

controls asks the browser to show playback controls. <source> identifies a media file and its format. Add your own media files at these paths before trying the example. Provide transcripts for audio and captions for spoken video so more people can use the content.

4. Choose the right kind of list

Use <ul> when the items have no required order. Use <ol> when their sequence matters. Each item belongs inside <li>. A nested list should be inside a list item, rather than placed directly between two items.

<ul>
    <li>Text editor</li>
    <li>Web browser</li>
</ul>

<ol>
    <li>Write the HTML.</li>
    <li>Save the file.</li>
    <li>Open it in a browser.</li>
</ol>

A description list pairs terms and explanations. <dl> holds the list, <dt> marks a term, and <dd> gives its description.

<dl>
    <dt>HTML</dt>
    <dd>Describes the structure of a web page.</dd>
    <dt>CSS</dt>
    <dd>Controls how that page looks.</dd>
</dl>

5. Use tables for related data

A table is useful when values belong in rows and columns. A marks table connects each student's name with a mark. It is not a general tool for laying out a whole website.

<table>
    <caption>Practice marks</caption>
    <thead>
        <tr>
            <th scope="col">Student</th>
            <th scope="col">Marks</th>
        </tr>
    </thead>
    <tbody>
        <tr><td>Ali</td><td>85</td></tr>
        <tr><td>Sara</td><td>91</td></tr>
    </tbody>
</table>

<tr> creates a row. <th> identifies a header cell, and <td> contains a data value. <thead> and <tbody> group header and body rows. A <tfoot> can hold totals or a summary. scope="col" identifies a column header.

colspan lets a cell occupy more than one column. rowspan lets it occupy more than one row. The remaining cells must still form a consistent table structure.

<tr>
    <td colspan="2">Both students passed.</td>
</tr>

Use CSS for borders and cell spacing. Older examples may use presentation attributes such as cellpadding or cellspacing, but a shared stylesheet keeps these appearance rules in one place.

6. Check the document, not just its appearance

A page can look acceptable while containing incorrectly nested elements. An HTML validator can help find missing attributes, invalid nesting and other markup problems. Fix the reported problem, then check the page again.

Validation is useful, but it does not guarantee that the writing is clear, the page is accessible or the design works well. Also check headings, link destinations, alternative text and the page at a narrow window size.

Try it yourself

  1. Create a page with a main heading, two paragraphs and an ordered list.
  2. Add a link to another page and a link to a section on the same page.
  3. Add a two-column table of subjects and credit hours.
  4. Explain the difference between <title> and <h1>.
