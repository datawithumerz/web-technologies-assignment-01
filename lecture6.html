The CSS Box Model and Display

Every element occupies space. Once you understand its content, padding, border and margin, spacing problems become easier to explain and fix.

1. Content, padding, border and margin

The box model, from inside to outside
PartWhat it meansExample
ContentThe area containing text, an image or child elements.The words inside a notice.
PaddingSpace between the content and the border.Room around the words inside the notice.
BorderThe boundary around content and padding.A green line around the notice.
MarginSpace outside the border.The gap between the notice and the next element.

If text feels pressed against an edge, increase padding. If two separate boxes feel too close, increase their margin. The element's background extends through its padding, while its margin remains outside that background.

<div class="demo-box">
    Padding gives this text room inside the border.
</div>
.demo-box {
    box-sizing: border-box;
    width: 250px;
    max-width: 100%;
    padding: 20px;
    border: 5px solid #244b43;
    margin: 20px 0;
    background-color: #edf2e7;
}

Browser result

Padding gives this text room inside the border.

The green border encloses the text and padding. The top and bottom margins create space outside it. max-width: 100% lets the example fit when its available space is narrower than 250 pixels.

2. What does width actually include?

The answer depends on box-sizing. With content-box, the declared width covers only the content. Padding and borders add to the visible box width.

.box {
    box-sizing: content-box;
    width: 250px;
    padding: 20px;
    border: 5px solid black;
}

The border-to-border width is 250 + 20 + 20 + 5 + 5 = 300px. Margins are outside that 300-pixel box. A 30-pixel margin on both sides would take another 60 pixels of horizontal space.

With border-box, the declared width includes the content, padding and borders. Using the same values, the outside box stays 250 pixels wide and the content area becomes 200 pixels.

.box {
    box-sizing: border-box;
    width: 250px;
    padding: 20px;
    border: 5px solid black;
}
Same declarations, different sizing rules
Sizing ruleContent widthWidth including padding and border
content-box250px300px
border-box200px250px

A common way to make dimensions easier to manage is to apply this rule at the start of a stylesheet:

* {
    box-sizing: border-box;
}

This selects every element. It changes how declared widths and heights are calculated; it does not remove padding or borders.

3. Shorthand and margin collapsing

Padding and margin accept one, two, three or four values. For four values, read them clockwise: top, right, bottom, left.

padding: 16px;                 /* All sides */
padding: 12px 20px;            /* Top/bottom, left/right */
padding: 10px 20px 30px;       /* Top, left/right, bottom */
padding: 10px 20px 30px 40px;  /* Top, right, bottom, left */

The same pattern applies to margin. You can also set one side directly, such as margin-bottom: 24px;.

Why do two margins sometimes make one gap?

Some vertical margins between ordinary block elements collapse. When two positive adjacent margins collapse, the resulting gap is the larger value instead of their sum.

.first {
    margin-bottom: 30px;
}

.second {
    margin-top: 20px;
}

If these are adjacent blocks in normal flow and their margins collapse, the gap is 30 pixels, rather than 50. Left and right margins do not collapse this way, and padding does not collapse.

A parent's top margin and its first child's top margin can also interact. Adding top padding or a top border to the parent separates them. This explains why a child's margin may seem to move a larger section instead of creating space inside it.

4. Flexible dimensions and overflow

A fixed width uses a value such as 400px. A percentage width responds to the containing block. Minimum and maximum properties place limits on how small or large a box can become.

.container {
    width: 92%;
    max-width: 920px;
    margin: 0 auto;
}

This container uses most of the available width on a small screen and stops growing at 920 pixels. The automatic left and right margins centre it. min-width, min-height and max-height provide other limits when they are needed.

A fixed height can cause trouble when text grows or wraps onto more lines. Let long reading sections grow naturally. When a deliberately limited box needs to contain extra content, use overflow.

Overflow values
ValueEffect
visibleExtra content can extend beyond the box.
hiddenExtra content is clipped without normal scrolling controls.
scrollCreates a scrolling box, even when content fits. Scrollbar appearance depends on the system.
autoProvides scrolling when content overflows.
.demo-scroll {
    height: 120px;
    padding: 12px;
    overflow: auto;
    border: 1px solid #81907d;
}

Browser result: scroll inside this box

This box has a fixed height of 120 pixels. Its content continues beyond the available vertical space.

Because it uses overflow: auto, you can scroll to read the remaining paragraphs. The surrounding page does not need to stretch the box.

This can be useful for a small preview, but normal lesson text is usually easier to read without a separate scroll area.

5. How display changes layout

The display property determines how an element participates in layout. Changing it affects the box's behaviour without changing the element's meaning in HTML.

Four useful display values
ValueLine behaviourDimensions and space
blockStarts on a new line.Can use width and height; normally fills available width.
inlineFlows within a line.For ordinary text elements, width and height do not control the box as they do for blocks.
inline-blockFlows inline and wraps when needed.Accepts width, height, padding and borders.
noneDoes not generate a visible box.Takes no layout space.

By default, a paragraph commonly behaves as a block and a span behaves inline. An image is a special inline element that can still have dimensions, so the normal text rule is not universal.

Inline-block example

<span class="demo-tag">HTML</span>
<span class="demo-tag">CSS</span>
<span class="demo-tag">The Web</span>
.demo-tag {
    display: inline-block;
    width: 100px;
    padding: 8px;
    margin: 4px;
    border: 1px solid #244b43;
    text-align: center;
}

The boxes remain beside one another when space allows and move onto another line when it does not. This is a simple way to style short navigation links or labels without a complex layout.

Hiding an element

.hidden-note {
    display: none;
}

display: none removes the element's box from the layout. visibility: hidden hides it while generally keeping its layout space. Neither technique removes the content from the HTML source or protects private information.

6. Borders, shadows and consistent spacing

A border shorthand contains its width, style and colour. You can style individual sides, round corners with border-radius, or add a subtle shadow.

.notice {
    padding: 16px;
    margin-bottom: 24px;
    border: 1px solid #b5c1b0;
    border-left: 4px solid #244b43;
    border-radius: 4px;
    box-shadow: 0 2px 6px rgba(0, 0, 0, 0.1);
}

In this shadow, the first two values are horizontal and vertical offsets. The third is blur, followed by the colour. A shadow adds a visual effect without changing the layout dimensions of the box.

Choose a small set of spacing values, such as 8, 16, 24 and 32 pixels, and reuse them. Consistent spacing makes headings, paragraphs and examples feel connected. You can build a clear page with basic widths, margins, padding and display rules.

Try it yourself

  1. Make a box 300 pixels wide with 20 pixels of padding and a 2-pixel border. Calculate its outside width using content-box, then check border-box.
  2. Increase padding and margin separately. Explain which space changes each time.
  3. Switch the example labels from inline-block to block.
  4. Narrow the browser window and watch the container and labels adapt.
