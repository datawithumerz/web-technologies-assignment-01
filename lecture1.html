LECTURE 1

Introduction to the Web

When you open a website, your browser asks another computer for information. Understanding this exchange makes terms such as server, hosting and HTTP much easier to remember.

1. Internet and the World Wide Web

The Internet is the worldwide network that connects computers and other devices. It carries many kinds of communication. The World Wide Web is a system of linked pages and resources that uses this network.

Think of the Internet as a road system. The Web is one service that uses those roads. Email can also use the Internet without being a web page, although a webmail service lets you read email through a browser.

Web page
A document a browser can display. An HTML file can describe its headings, paragraphs, links and other content.
Website
A collection of related pages and resources. A university website may contain separate pages for departments, admissions and contact details.
Web browser
Software that requests and displays web resources. It reads HTML and CSS to build the page you see.
Web server
Software, and the computer running it, that receives requests and sends resources or generated responses.

2. What do you need to make a website?

You can begin with a text editor and a browser. Write a page in the editor, save it with the .html extension, and open it in the browser. Editing the source changes what the browser can display after a refresh.

From writing a page to publishing it
Tool or serviceWhat it does
Text editorLets you write the HTML and CSS yourself.
Web authoring tool or IDECan provide suggestions, error hints and other development tools. A WYSIWYG editor shows a visual result while you edit.
Upload or publishing toolTransfers your files to a server. FTP is one file-transfer method discussed in web publishing.
Hosting serviceProvides the place and service that make your website available over the Web.
BrowserRetrieves the page and displays the result for the visitor.

A file saved on your laptop is a local file. Other people cannot open it over the public Web simply because you can see it. Publishing places the site on a server where visitors can reach it through a web address.

What is a web platform?

A web platform provides tools or an environment for creating and using web services. It can include a user interface, servers, databases, content management and security features. APIs allow different software systems to exchange information. A shopping platform, for example, connects product pages with stock information and payment services.

3. The request and response cycle

The browser acts as a client. It requests a resource, and the server returns a response. For a typical hosted page, the process is:

  1. You enter a URL or follow a link.
  2. The browser obtains the server's address, often using DNS.
  3. It connects to the server and sends an HTTP request.
  4. The server returns a response, such as an HTML document.
  5. The browser reads the HTML and requests linked resources, such as a stylesheet or images.
  6. It combines these resources to display the page.

HTML describes the content. CSS controls its appearance. JavaScript can add programmed behaviour, but a useful website can also consist of linked HTML pages and CSS alone.

4. Understanding a web address

A URI identifies a resource. A URL is a type of URI that describes how to locate or access it. In everyday browsing, the address you enter is a URL.

https://example.com:443/courses/web.html?unit=1#topics
Parts of the example URL
PartMeaning
httpsThe scheme: how to access the resource.
example.comThe domain name identifying the host.
:443The port. HTTPS normally uses 443, so it is often omitted.
/courses/web.htmlThe path of the resource.
?unit=1A query containing an extra value.
#topicsA fragment pointing to a place within the page. This part is handled by the browser.

DNS, the Domain Name System, helps translate domain names into IP addresses. People remember names more easily, while network communication uses addresses. DNS is like a contact list that helps you find the address associated with a name.

5. HTTP and HTTPS

HTTP is a protocol: a set of communication rules for requests and responses. HTTPS protects HTTP communication using TLS. It encrypts data in transit and helps the browser authenticate the server.

Request methods

  • GET asks for a resource, such as a lecture page.
  • POST submits data for processing, such as form details.
  • PUT usually replaces a resource, while PATCH applies a partial update.
  • DELETE requests removal of a resource.

Response status codes

A response includes a status code describing the outcome. The first digit tells you the general category.

HTTP status families
FamilyMeaningExample
1xxInformation about progress100 Continue
2xxSuccess200 OK
3xxRedirection-related response301 Moved Permanently
4xxA request-related problem404 Not Found
5xxA server-side problem500 Internal Server Error

Headers carry extra information. For example, Content-Type: text/html tells the browser that the response contains HTML. An Authorization request header can carry credentials for a protected resource.

A small HTML response

The server might return HTML containing the following elements. The browser displays the heading and paragraph instead of showing the tags themselves.

<h2>Welcome to the Web</h2>
<p>A browser displays the content of this page.</p>

Browser result

A browser displays the content of this page.
